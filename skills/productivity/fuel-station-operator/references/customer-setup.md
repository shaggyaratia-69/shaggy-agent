# Customer setup for fuel station workflows

Configure these items after installing Shaggy Agent:

- Fuel vendor portal credentials in secure storage.
- Station/location list with site codes and addresses.
- Tank capacities, reorder triggers, and dispatch contacts per location.
- Google/Excel output destination if used.
- Firecrawl or preferred extraction API key if web extraction is needed.
- Email account only if Shaggy will draft or send dispatch/vendor emails.

Do not paste passwords into normal chat. Use Shaggy setup secrets, OS Keychain/Credential Manager, browser saved login, or environment variables.
